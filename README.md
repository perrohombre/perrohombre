## 🧠 Team Brain

> **[perrohombre/TEAM_BRAIN](https://github.com/perrohombre/TEAM_BRAIN)** — master's thesis project

A RAG-based knowledge management system for development teams. Notes are vectorized, linked into a knowledge graph, and served to both a web frontend and IDE agents.

![Team Brain — knowledge graph workspace](TeamBrain.png)

- **Agentic retrieval** — a tool-use loop that decides how to search instead of running a single fixed query
- **Hybrid search** — vector + keyword retrieval over Weaviate
- **Knowledge-graph frontend** — notes and their relations are browsable, not just searchable
- **MCP server** — exposes the whole knowledge base to IDE agents through the Model Context Protocol
- **Evaluated with a systematic ablation study** of the individual pipeline components

`FastAPI` `MongoDB` `Weaviate` `Anthropic Claude` `Next.js` `MCP`

## 🪐 AstroBridge

> **[kubamale/BHL-SW-BONSAI](https://github.com/kubamale/BHL-SW-BONSAI)** — winner, Best Hacking League 2024 (BEST, P&G, 42 Warsaw)

A time synchronization system between Earth (Gregorian calendar) and Mars (Darian calendar), letting you manage events across both planetary time systems — precise time conversion, a RESTful API for event handling, and real-time synchronization.

`Spring Boot` `Next.js` `React` `TypeScript` `MySQL`
